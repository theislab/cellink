## DonorData

cellink works on {class}`donordata.DonorData` objects from the [DonorData](https://donordata.readthedocs.io) package,
available as `cellink.DonorData`. In cellink the donor level `dd.D` holds the genotypes. The
[DonorData documentation](https://donordata.readthedocs.io) describes the object, its sample level and its
[file format](https://donordata.readthedocs.io/en/latest/io/spec.html); {doc}`io` reads and writes it with cellink's
genotype storage.
